-- Modular Crawlers
    Supports Scrapy (static data) and Selenium (JavaScript-heavy sites).
    Each crawler is independent and reusable.

-- API endpoints:
    POST /api/v1/crawler/start -> Start a crawler
    POST /api/v1/crawler/stop -> Stop a crawler
    GET /api/v1/data -> Retrieve crawled data

-- Asynchronous Execution:
    Uses Celery / RabbitMQ / Kafka to manage crawling tasks.
    Allows parallel crawling without blocking API.

-- Task Scheduling:
    Uses APScheduler / Celery beat to automate crawling at intervals.

-- Database & Storage
    Stores structured data in PostgreSQL.
